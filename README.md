# Travel Agency Dashboard

A TypeScript dashboard application for travel-related data and administration, built with React Router and a component-rich data visualization stack.

## Highlights

- Admin and root route groups
- Dashboard-oriented responsive UI
- Charts, data grids, dropdowns, and maps with Syncfusion
- Appwrite integration
- TypeScript-first codebase
- Tailwind CSS styling

## Tech Stack

- React 19
- React Router 7
- TypeScript
- Vite
- Tailwind CSS
- Appwrite
- Syncfusion
- Axios
- Day.js

## Run Locally

```bash
git clone https://github.com/eduardolluis/travel-agency-dashboard.git
cd travel-agency-dashboard
npm install
npm run dev
```

Useful scripts:

```bash
npm run build
npm run typecheck
npm start
```
